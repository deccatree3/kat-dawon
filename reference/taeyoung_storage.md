# 태영종합물류(용인) 보관비 검수 레퍼런스 — 네이처뉴트리션

물류사 변경(다원 → 태영) 이후 보관비 분석용 누적 기록. 새 정보가 들어오면 이 파일에 추가한다.

## 1. 확정 기준

## 2. 1팔레트 적재량 기준 (우선순위)

1. **생산 입고 시 적재** (아래 3장) — 있으면 최우선 (보관 중 PLT는 이 이하가 정상)
2. 태영 보관내역 K열 `파렛트당 수량` (= 박스입수 × 파렛트당 박스 수)
3. 대략 기준: **20카톤 = 1PLT** (카톤입수량은 kat-outbound-hub DB `wms_product.box_qty`)
4. 부자재: 명진패키지 발주서 Sheet2의 **MOQ = 1PLT 물량**
   (`네뉴_예리\1. 발주서\2.부자재 발주서\4.명진패키지(번들박스)\251226_..._번들박스.xlsx`)

## 3. 생산 입고 시 적재 기록 (SKU별)

**최초 생산 후 물류센터 입고 시점**의 팔레트 구성(공장 출하 적재). 보관 중 피킹으로 수량이 줄면 PLT 수는 이 이하가 정상 → 입고 후 PLT가 늘었다면 재적재 사유 확인 대상.

출처: 2026-10-23 방탄커피 2종·4in1 콜라겐 개별 확인 → **2026-10-29 자체 정리표로 21종 일괄 갱신**.

수량 컬럼 정의:
- **실제입고**: MOQ 기준으로 실제 입고된 수량. 생산이 카톤 단위로 딱 떨어지지 않아 여분이 조금씩 붙는다(예: 6,080 = 6,000 + 여분 80).
- **카톤 기준**: 카톤입수 × 카톤 수로 딱 떨어지는 수량.
- `PLT당 개수` = 실제입고 ÷ 입고 PLT라서 여분이 섞여 있다(예: 맥주효모환 6,080 ÷ 3 = 2,027). **태영 K와 비교할 때는 `PLT당 카톤 × 카톤입수`(여분 제외)를 쓴다.**
- `태영 K(9월)`는 9월 보관내역의 `파렛트당 수량`(K열)이며, 확인된 품목만 적었다. 카톤 기준 PLT당 수량이 태영 K보다 크면 태영이 PLT를 과다 산정하는 방향이라 클레임 근거가 된다.

- **①유형 클레임 후보**(카톤 기준 PLT당 수량 > 태영 K): 방탄커피 2종만 해당한다. 맥주효모환·낙산균은 여분을 빼면 태영 K와 일치하므로 해당 없음.

### 태영 마스터 컬럼 신뢰도 (2026-10-23 점검)
- `파렛트당 수량`(K) = 박스입수(I) × 파렛트당 박스(J) — 전 행 수식 일치. 독립 정보 아님
- `박스입수`(I): 우리 DB와 30/35 SKU 일치 → 대체로 신뢰
- `파렛트당 박스`(J): **입고 실측 2건 모두 과소** (데일리 48<60, 닥터 24<26). 같은 박스입수 품목끼리 값이 일률(120입=24, 60입=20, 티=32) → 실측보다 템플릿성 값 의심. 검증 전까지 PLT 과다 산정 방향으로 작용
- `박스수량 합계`(Z)·`잔여 수량`(AA)은 **가용재고(W) 기준**으로 계산됨 (Z×I+AA=W, 전 행) → 태영 시스템의 기준 수량은 가용재고로 추정. 현재고(G)는 의미 확인 필요
- 마스터 없음(I·J=0): 블랙마카, 3개입 지함·쇼핑백 4종

DB 미매칭(카톤입수 없음): 보틀(트라이탄보틀), 스키니퓨리티 선물세트 쇼핑백, 퍼펙토 선물세트 3개입 지함·쇼핑백 4종.
