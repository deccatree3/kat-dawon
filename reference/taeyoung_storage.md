# 태영종합물류(용인) 보관비 검수 레퍼런스 — 네이처뉴트리션

물류사 변경(다원 → 태영) 이후 보관비 분석용 누적 기록. 새 정보가 들어오면 이 파일에 추가한다.

## 1. 확정 기준

| 항목 | 내용 |
|---|---|
| 분석 범위 | 태영은 **보관비만** 분석 |
| 단가 | 18,000원/PLT (다원과 동일, 검증 대상 아님) |
| 측정 시점 | **월말 기준** PLT 수 |
| RAW | 청구 파일 `보관내역` 시트 (1행 = SKU×로트×존, L열 파렛트 수량 수기, L54 합 + 부자재 행 = 청구 PLT) |
| 목적 | 우리 재고가 적정 PLT 수로 보관되는지 → 과사용 시 증빙과 함께 클레임 |
| 분석 방식 | ① 당월 RAW 단독 (적정 PLT 계산) ② 전월 대비 (재고 증감 vs PLT 증감) |
| 로트 혼적 | 우리 입장: 섞어도 됨. **현장 운영 방식 확인 필요** |
| 재고 컬럼 | 현재고(G)·가용재고(W) 차이 원인 불명 → 둘 다 계산 |

## 2. 1팔레트 적재량 기준 (우선순위)

1. **생산 입고 시 적재** (아래 3장) — 있으면 최우선 (보관 중 PLT는 이 이하가 정상)
2. 태영 보관내역 K열 `파렛트당 수량` (= 박스입수 × 파렛트당 박스 수)
3. 대략 기준: **20카톤 = 1PLT** (카톤입수량은 kat-outbound-hub DB `wms_product.box_qty`)
4. 부자재: 명진패키지 발주서 Sheet2의 **MOQ = 1PLT 물량**
   (`네뉴_예리\1. 발주서\2.부자재 발주서\4.명진패키지(번들박스)\251226_..._번들박스.xlsx`)

## 3. 생산 입고 시 적재 기록 (SKU별)

**최초 생산 후 물류센터 입고 시점**의 팔레트 구성(공장 출하 적재). 보관 중 피킹으로 수량이 줄면 PLT 수는 이 이하가 정상 → 입고 후 PLT가 늘었다면 재적재 사유 확인 대상.

| 기록일 | SKU | 바코드 | 입고수량 | 카톤 | 카톤입수 | 입고 PLT | 입고 PLT당 | 태영 마스터 PLT당 | 9월 보관내역 대조 |
|---|---|---|---|---|---|---|---|---|---|
| 2026-10-23 | 데일리키토 방탄커피(14포) | 8809647580140 | 4,800 | 240 | 20 | **4** | 60카톤 / 1,200개 | 48박스 / 960개 | 로트 20280713 현재고 4,298(가용 4,800)인데 **5 PLT** → 입고 4장보다 +1 (재고는 줄었는데 PLT 증가) |
| 2026-10-23 | 닥터키토 방탄커피(10포) | 8809647580041 | 2,496 | 52 | 48 | **2** | 26카톤 / 1,248개 | 24박스 / 1,152개 | 로트 20280713 현재고 2,496 = **입고 수량 그대로(미출고)** 인데 **3 PLT** → 입고 2장보다 +1 |

> 시사점: 태영 마스터의 파렛트당 박스 수가 입고 적재보다 작게 잡혀 있어(48<60, 24<26), 마스터대로 PLT를 산정하면 입고 때보다 팔레트가 늘어난다. 특히 닥터키토는 손대지 않은 입고분이 2→3장이 된 것이라 **재적재(풀어서 다시 쌓음) 사유**를 물을 수 있는 가장 강한 증빙.

## 5. 월별 결과

### 2026-09 (첫 공유 월 → 기준선)
- 청구 88 PLT = 상품 75 (마스터 있음 71 + 지함·쇼핑백 4) + 부자재 13
- 상품 적정 (태영 마스터, SKU 단위): 현재고 66 / 가용재고 67 → 청구 71 대비 순 +5 / +4
  - 초과 8종(각 +1, 로트 분리): 닥터키토 방탄커피, 슈링티, 맥주효모환, 펌킨펌킨티, 낙산균 루테리, 산양유 락토페린, 글루타치온 콜라겐, 흑마늘 아르기닌
  - 부족 3종: 반품존 방탄커피 9개, 슈퍼프레쉬티 5개, 트라이탄보틀(2.001장)
- 상품 적정 (20카톤 기준): 현재고 74 / 가용 78 → 청구 68보다 많음
- 부자재 적정 (MOQ 기준, 10/1 재고): 번들박스 9종 19 PLT + 지함 3종 → 청구 13보다 많음
- **결론: 전체 과사용 아님.** 클레임 후보는 로트 분리 PLT와 입고 적재 대비 초과(방탄커피 2종 각 +1, 특히 닥터키토 미출고분 2→3장)
